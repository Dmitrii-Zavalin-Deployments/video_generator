# 🎞️ Video Generator

## 🛠️ Description
A deterministic post‑processing engine that assembles processed frames into a final encoded video.  
It ingests a ZIP archive of frames, validates all inputs via strict JSON Schemas, applies video quality and encoding parameters, and produces a reproducible output video file.
